# 棋盘标记、候选与提示交互设计

日期：2026-08-20  
范围：对局页的选格高亮、标记工具、候选显示、提示卡片。不包含新的求解技巧。

## 目标

让标记可预期、提示不挡棋盘、候选笔记与自动候选互不覆盖，界面底盘黑白，彩色只出现在用户/提示标记上。

## 非目标

- 不新增求解器技巧。
- 不把同数字高亮做成标记层或色板功能。
- 不把数字键同时用于填数、上色和全盘过滤。

## 已确认的交互

### 同数字弱高亮（与标记无关）

- 仅当标记未开启时生效。
- 选中一格成数（已填数字）：弱高亮盘面上所有相同成数，以及所有该数字的候选。
- 这是选格的副作用：不写 `BoardMarkup`、不占用色板。
- 标记开启后关闭这层高亮，避免和格色/候选色/链叠色。
- 选空格时仍只做行/列/宫关联底色。

### 标记：互斥模式

一次只开一种模式：

| 模式 | 点击行为 |
| --- | --- |
| 关闭（默认） | 选格；成数触发同数字弱高亮；数字键填数或记笔记 |
| 格色 | 先选色块，再点格子上色；同色再点取消 |
| 候选色 | 先选色，再选格；数字键只启用该格已有候选（自动 ∪ 笔记）；点数字给该候选画小圆背景；同色再点取消 |
| 强链 / 弱链 | 点第一个候选（格内点或「选格 + 数字键」）用实心圆标起点，再点第二个画箭头；状态文案：「已选起点，再点终点」 |
| 自动共轭 | 先点数字，自动画出该数字在所有行、列、宫中恰好两处的共轭对 |

未进入格色模式时，点格子只选中，不上色。

色板为固定彩色档（金/绿/蓝/红等），格色与候选色共用。应用外壳、按钮、棋盘线用黑白/灰度；不把用户候选色改成灰阶。

删除「画共轭」按钮（目前只扫行）以及单独的手动画「共轭」芯片。共轭对只通过「自动共轭」生成，箭头类型仍为 `ArrowKind.conjugate`。强链、弱链保持手动画。

### 提示

- 参与格、删除候选、链箭头画在棋盘上（`hintMarkup`）。
- 说明文字与「取消 / 应用」放在棋盘正下方卡片，不使用挡住棋盘的 `AlertDialog`。
- 深搜询问、深搜失败同样走这张卡片。
- 验证、重置、胜利、自动填充候选等与棋盘高亮无关的确认，仍可用对话框。

### 候选两套集合

- `candidates`：由已填数字和 `eliminated` 自动计算，求解器只读这一套。
- `userCandidates`：用户笔记，只增删自身。
- `eliminated`：逻辑删除（应用提示等）。

显示为 `candidates ∪ userCandidates`。自动候选为 `{8}` 时再记 `2`，格子显示 `2` 和 `8`；`8` 不因笔记非空而被整格替换掉。笔记中多出的数字用稍重字重区分，不另开一层宫格。

## 数据与组件

- `GameState` 增加 `MarkupMode`；`pendingArrowKind` 由模式推导，不再和「标记总开关 + 点格即上色」并存。
- `arrowAnchor` 在链模式下保留，并在棋盘上画实心圆。
- `displayMarkup` 仍合并 `userMarkup` 与 `hintMarkup`。
- 同数字弱高亮由 `SudokuGrid` 根据「标记关闭 + 选中格有成数」计算，不写入 markup。
- 新增对局内 `HintPanel`（棋盘与控制按钮之间）。`getHint` 仍先写 `hintMarkup` 再展示卡片。
- `paintConjugates` 扩展为行、列、宫；由自动共轭模式 + 数字键触发。
- 主题：`AppTheme` 种子色改为近黑中性色，使按钮/导航/卡片偏黑白；标记色板保持独立常量，不受主题灰度化。

## 失败与边界

- 自动共轭时该数字没有任何行/列/宫双点：不画线，用一句短提示说明。
- 链模式只点了起点就切走模式：丢弃 `arrowAnchor`。
- 提示卡片打开时棋盘保持可点击查看，但不在卡片未关闭时开始新的提示。
- 数字键在候选色模式下：该格没有的候选为禁用，点击无效果。

## 测试

- 笔记：仅 `{8}` 的自动候选格 `toggleUserCandidate(2)` 后，显示包含 `2` 和 `8`。
- 标记关闭：选中成数 `5` 的格子，其它 `5` 成数与候选 `5` 进入弱高亮集合；打开任意标记模式后该集合为空。
- 格色：模式关闭时 `selectCell` 不写 `cellColors`；格色模式 + 选色后点格才写入。
- 候选色：选色、选格、点数字键后对应 `candidateColors` 有值，渲染为圆背景而非只改字色。
- 链：第一点后 `arrowAnchor` 非空；第二点后出现箭头且锚点清空。
- 自动共轭：行、列、宫各有一对时各画一条，不再只处理行。
- 提示：对局页找 `HintPanel` 文本与应用按钮；查找不应出现盖住棋盘的提示 `AlertDialog`（可用 `find.byType` 限定）。

## 决策记录

- 提示位置：棋盘下方卡片（非右侧栏、非半遮抽屉）。
- 标记工具：互斥模式（非「标记总开关 + 点格即上色」）。
- 「画共轭」改为按数字自动标行/列/宫共轭对。
- 点成数弱高亮是非标记功能，仅标记关闭时有效。
