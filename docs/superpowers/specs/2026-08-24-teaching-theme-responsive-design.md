# 数独教学内容、主题与移动端布局改进设计

## 目标

本轮解决七项已确认的问题：

1. 为技巧目录中的每项技巧提供真实、独立、完整的固定教学示例。
2. `main` 分支更新后自动构建并发布 Flutter Web 到 GitHub Pages。
3. 点击成数时，用背景而非字色突出全盘相同成数和候选。
4. 在系统亮暗模式之上增加可持久化的氛围强调色。
5. 提示出现时保持棋盘位置和尺寸不变。
6. 操作区默认紧贴棋盘，而非贴住屏幕底部。
7. 自动强链以无方向线段显示；手动画链和技巧推理链保留箭头。

## 1. 技巧说明

### 内容模型

`TechniqueInfo` 不再只有一行摘要、通用题目和通用标记，而是包含：

- 技巧名称和难度顺序；
- 简短摘要，用于目录预览；
- 完整定义；
- 识别条件；
- 本例推理步骤；
- 结论（填数或删除候选）；
- 易错点或适用限制；
- 图例；
- 专属固定盘面；
- 该盘面的候选状态；
- 格子、候选和链的预置标记。

所有现有目录条目都必须有独立示例，不允许回退到共享占位盘面。例题优先采用公开的 SudokuWiki、HoDoKu 或可验证的等价盘面，并以本地静态数据随应用发布。每个例题在录入时由对应 finder 或独立断言验证，确保盘面确实存在所声称的技巧和结论。

### 页面结构

移动端页面自上而下排列：

1. 技巧名称；
2. 固定尺寸的只读棋盘；
3. 图例；
4. “本例怎么推”；
5. “技巧定义”；
6. “识别方法”；
7. “注意事项”。

页面整体可滚动，但棋盘自身不参与缩放或动态推演。

### 视觉语言

- 起点：绿色候选圆底；
- 终点：黄色候选圆底；
- 中间节点：蓝色候选圆底；
- 删除目标：目标格浅黄底，候选红色圆底；
- 强链：实线；
- 弱链：虚线；
- 本例有推理方向的链允许箭头；
- 无方向关系只画线段。

数组、鱼、区块等不适用“起点/终点”的技巧，按参与格、基底单位、覆盖单位和删除目标分别着色，不强行套用链式图例。

### 数据组织

技巧内容按类别拆分为多个 Dart 数据文件，避免单一目录文件继续膨胀：

- 基础与数组；
- 区块与鱼；
- 翼、矩形和着色；
- 链与环；
- ALS 与强制类技巧。

`TechniqueCatalog` 只负责合并、排序和按 ID 查找。页面只消费统一的 `TechniqueInfo`，不包含技巧特例判断。

## 2. GitHub Pages 自动发布

新增 GitHub Actions 工作流，在以下条件触发：

- 推送到 `main`；
- 手动触发。

流程：

1. 检出代码；
2. 安装项目所需 Flutter 稳定版；
3. 执行 `flutter pub get`；
4. 执行 `flutter analyze`；
5. 执行 `flutter test`；
6. 执行 `flutter build web --release --base-href /sudoku-dart/`；
7. 发布 `build/web` 到 GitHub Pages。

使用 GitHub 官方 Pages artifact/deploy actions 和 `pages: write`、`id-token: write` 权限，不再维护嵌套 Git 仓库或手工强推 `gh-pages`。构建或测试失败时不得发布。

## 3. 同数字背景高亮

仅在没有活动提示、没有标记模式且用户点中一个成数时启用：

- 所有相同成数所在格使用当前强调色作为整格背景；
- 成数文字使用基于背景亮度计算的对照色；
- 所有相同数字的可见候选使用强调色小方/圆角矩形背景；
- 候选文字使用对照色；
- 其它候选和成数保持正常样式。

优先级从高到低：

1. 用户或提示标记；
2. 冲突；
3. 当前选中格；
4. 同数字高亮；
5. 相关行、列、宫；
6. 普通宫底色。

隐藏候选仍是严格视图开关；关闭后，同数字候选高亮也不得让候选重新出现。

## 4. 主题氛围色

### 行为

- 亮暗模式继续跟随系统；
- 用户可独立选择强调色；
- 选择持久化到本地，重启后恢复；
- 默认使用截图参考的蓝色。

首批提供蓝、青绿、琥珀和玫红四套强调色。颜色选择放入应用设置入口。

### 覆盖范围

强调色用于：

- 手填成数；
- 当前选中格和弱相关格；
- 同数字成数背景；
- 同数字候选背景；
- 数字键的可用、选中和笔记状态；
- 激活按钮、导航指示器和选中芯片；
- 强链的默认颜色。

页面大背景、普通棋盘格、普通候选和粗细网格线仍保持中性，以保证数独内容和用户标记色可辨。

### 架构

新增应用级 `ThemeController`，保存当前强调色 ID，并生成对应的明暗 `ThemeData` 与 `BoardPalette`。组件只引用 `ColorScheme` 和 `BoardPalette` 语义令牌，不直接读取具体色值。

## 5. 固定棋盘与提示底部抽屉

### 对局布局

布局从“整页 Column 共同分配高度”改为：

1. 信息栏；
2. 固定宽高比棋盘；
3. 紧贴棋盘的操作区；
4. 数字键区；
5. 剩余空间。

棋盘尺寸只由屏幕宽度、横向安全边距和预设最大宽度决定，不由提示内容或剩余纵向空间决定。屏幕高度不足时，棋盘以下区域允许滚动；不得缩小棋盘来容纳控件。

### 提示抽屉

提示以同一页面上的持久底部抽屉显示：

- 覆盖操作区和数字键区；
- 不覆盖、不推动、不缩放棋盘；
- 抽屉高度受可用区域限制，长文案在抽屉内部滚动；
- 抽屉保留关闭和应用按钮；
- 应用当前提示后不关闭，立即查找下一步并原地替换内容；
- 深度搜索询问和搜索失败也在同一抽屉状态机中显示；
- 只有用户关闭、离开对局或重开棋盘时收起。

抽屉使用现有 `HintSession` 作为唯一状态源，不另建平行的 UI 状态。

## 6. 自适应操作区

- 竖屏手机：操作区紧贴棋盘下方，数字键随后；
- 高屏手机或平板：仍保持贴近棋盘，多余空间留在操作区下方；
- 矮屏手机：棋盘以下内容滚动，棋盘保持固定；
- 宽屏：棋盘和操作区可并排，但操作区顶部与棋盘顶部对齐，不垂直贴底。

自适应断点只改变排列方式，不改变功能顺序或状态。

## 7. 自动强链无箭头

`MarkupArrow` 增加“是否有方向”的视觉属性：

- 自动强链生成 `directed: false`，画实线但不画箭头；
- 手动强链、手动弱链保持 `directed: true`；
- 技巧提示根据逻辑含义明确指定。表示传播方向时有箭头，仅表示双向强关系时无箭头。

自动强链仍扫描行、列、宫中恰有两个该数字候选的位置，逻辑不变，只改变视觉表达。重复检测忽略端点顺序。

## 错误处理与可访问性

- 教学示例缺失或格式错误时，测试失败；生产页面不展示半成品占位盘。
- 本地主题偏好读取失败时回退到默认蓝色。
- GitHub Actions 中任一检查失败时停止发布。
- 强调背景与文字至少达到 WCAG AA 对比度。
- 颜色之外继续用实线/虚线、箭头/无线头和文字图例表达含义，避免仅靠色觉区分。
- 提示抽屉支持键盘焦点和语义标签，关闭后焦点回到提示按钮。

## 测试与验收

### 教学内容

- 每个目录 ID 都有独立盘面、完整段落和非空标记；
- 每个示例盘面为 81 字符且候选状态合法；
- 对可由 finder 验证的技巧，finder 返回对应技巧及相同结论；
- 页面测试验证棋盘、图例和所有说明分区存在。

### 高亮与主题

- 点击成数后，相同成数整格和候选小格使用当前强调色背景；
- 字色按背景自动取对照色；
- 切换四种强调色后，亮暗主题和棋盘令牌同步变化；
- 主题偏好可恢复；
- 活动提示、标记模式、隐藏候选时维持既有屏蔽规则。

### 布局

- 在常见手机尺寸上，提示出现前后棋盘边长和屏幕坐标不变；
- 抽屉覆盖操作区，不覆盖棋盘；
- 连续应用提示时抽屉保持打开；
- 高屏设备的操作区紧贴棋盘；
- 矮屏设备无 overflow，棋盘下方可滚动；
- 宽屏操作区与棋盘顶对齐。

### 强链

- 自动强链无箭头；
- 手动画链和有方向的提示链仍有箭头；
- 自动强链重复检测不受端点方向影响。

### 发布

- 工作流仅在 analyze、test、web build 全部通过后部署；
- Pages 产物包含正确的 `/sudoku-dart/` base href；
- 部署后的首页和静态资源返回成功状态。
