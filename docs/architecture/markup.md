# 棋盘标记与候选

对局页的选格高亮、标记工具和候选显示。提示怎么画在棋盘上，也走同一套 `BoardMarkup`。

## 同数字弱高亮

与标记层无关：

- 仅当标记未开启、也没有活动提示时生效。
- 选中一格成数：弱高亮盘面上所有相同成数，以及所有该数字的可见候选。
- 不写 `BoardMarkup`、不占用色板。
- 选空格时只做行 / 列 / 宫关联底色。

## 标记：互斥模式

一次只开一种模式：

| 模式 | 点击行为 |
| --- | --- |
| 关闭（默认） | 选格；成数触发同数字弱高亮；数字键填数或记笔记 |
| 格色 | 先选色块，再点格子上色；同色再点取消 |
| 候选色 | 先选色，再选格；数字键只启用该格已有候选（自动 ∪ 笔记）；点数字给该候选画圆底；同色再点取消 |
| 强链 / 弱链 | 点第一个候选标起点，再点第二个画箭头 |
| 自动共轭 | 先点数字，自动画出该数字在所有行、列、宫中恰好两处的共轭对 |

未进入格色模式时，点格子只选中，不上色。格色与候选色共用固定色板。应用外壳、按钮、棋盘线用中性色；彩色只出现在用户 / 提示标记和强调色上。

共轭对只通过「自动共轭」生成，类型仍是 `ArrowKind.conjugate`。强链、弱链保持手动画。自动强链画实线、不画箭头；手动画链和有方向的提示链保留箭头。

## 候选两套集合

- `candidates`：由已填数字和 `eliminated` 自动计算，求解器只读这一套。
- `userCandidates`：用户笔记，只增删自身。
- `eliminated`：逻辑删除（应用提示等）。

显示为 `candidates ∪ userCandidates`。自动候选为 `{8}` 时再记 `2`，格子同时显示 `2` 和 `8`。笔记中多出的数字可用字重区分，不另开一层宫格。手动划掉只影响显示，不进 `eliminated`。

## 提示高亮

参与格、删除候选、链箭头画在棋盘上（`hintMarkup`），与用户标记合并为 `displayMarkup`。说明文字在底部抽屉，不挡棋盘；见 [界面与教学内容](./ui.md)。

## 数据

- `GameState.MarkupMode`；链模式下保留 `arrowAnchor`。
- 同数字弱高亮由棋盘根据「标记关闭 + 选中格有成数」计算。
- `paintConjugates` 扫描行、列、宫。
- 组件只引用 `ColorScheme` 和 `BoardPalette` 语义令牌。
