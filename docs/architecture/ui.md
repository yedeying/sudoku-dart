# 界面与教学内容

对局布局、主题、技巧说明页，以及 Web 发布。

## 技巧说明

每条技巧一页，数据是完整的 `TechniqueInfo`：名称、摘要、定义、识别条件、本例推理、结论、注意事项、图例、专属盘面、候选状态、预置标记。不允许回退到共享占位盘。

页面自上而下：技巧名、固定尺寸只读棋盘、图例、「本例推导」、定义、识别方法、注意事项。棋盘不缩放、不推演。右上角复制例题；对局图标带着当前盘和候选直接打开棋盘（底下切到对局页签，返回落在对局首页）。

视觉语言：

- 起点：绿色候选圆底；终点：黄色；中间节点：蓝色
- 删除目标：格浅黄底，候选红色圆底
- 强链实线，弱链虚线；有推理方向才画箭头

数组、鱼、区块按参与格、基底单位、覆盖单位和删除目标着色，不强行套链式图例。

`TechniqueCatalog` 只合并、排序和按 ID 查找。例题按家族拆在 `lib/models/technique_examples_*.dart`。

## 主题

亮暗跟随系统。用户可另选强调色（蓝 / 青绿 / 琥珀 / 玫红），本地记住。强调色用于手填成数、选中与弱相关格、同数字高亮、数字键状态、激活控件和默认强链色。页面大底、普通格、普通候选和网格线保持中性。

`ThemeController` 生成对应的明暗 `ThemeData` 与 `BoardPalette`。

同数字高亮：无活动提示、无标记模式、点中成数时，相同成数整格和该数字可见候选用强调色底，文字取对照色。隐藏候选是视图开关，关掉后同数字高亮也不得把候选叫回来。

优先级：用户或提示标记 > 冲突 > 当前选中格 > 同数字高亮 > 相关行/列/宫 > 普通宫底。

## 对局布局

1. 信息栏
2. 固定宽高比棋盘（只由屏宽和最大宽度决定）
3. 紧贴棋盘的操作区
4. 数字键
5. 剩余空间

高度不够时，棋盘以下可滚，不得缩小棋盘。宽屏时操作区可与棋盘并排，顶对齐。

## 提示抽屉

- 覆盖操作区和数字键，不覆盖、不推动、不缩放棋盘
- 长文案在抽屉内滚动
- 应用后不关闭，立刻换成下一步
- 深度搜索询问和失败走同一套 `HintSession`
- 用户关闭、离开对局或重开棋盘时才收起

## Web 发布

推送 `main` 或手动触发 `.github/workflows/deploy-pages.yml`：

1. `flutter pub get`
2. `flutter analyze`（有 issue 即失败，含 info）
3. `flutter test`
4. `flutter build web --release --base-href /sudoku-dart/`
5. 发布 `build/web` 到 GitHub Pages

分析或测试失败不得发布。在线地址：<https://yedeying.github.io/sudoku-dart/>
