# Hodoku 记号

教学文案和提示文案不用「第 x 行第 x 列」。格子、候选、链统一成 Hodoku 记号。

| 对象 | 写法 | 例 |
|---|---|---|
| 格子 | `r{行}c{列}`，行列表 1–9 | `r3c5` |
| 候选 | `{数字}{格子}` | `6r3c5` |
| 行 / 列 / 宫 | `r3` / `c5` / `b5`（宫 1–9，行优先：上左=1） | |
| 填数结论 | `填 r3c5=8` | |
| 删除结论 | `删 6r1c2, 6r1c5` | |
| 强链 | `=` | |
| 弱链 | `-` | |
| 链 | 候选用 `=` / `-` 交替连接，两端空格 | `6r3c5 = 6r3c8 - 6r7c8 = 6r7c5` |

分组节点写成 `{6r7c2, 6r8c2, 6r9c2}`。

整行 / 整列可用「r3 上数字 6 只出现在 c5 和 c8」，不要再展开成「第 3 行…第 5 列和第 8 列」。

## 提示

`SudokuHint.explanation` 和提示抽屉副行都用上表。

- 填数：`填 r3c5=8`
- 删除：`删 6r1c2, 6r1c5`
- 链类：解释里必须有一行链表达式
- 鱼 / 数组：用 `r2,r8` × `c3,c5` 或格子列表

拼串走 `lib/models/notation.dart`（`cellRef`、`candRef`、`chainExpr`、`fillLine`、`elimLine` 等），finder 里不手写「第 n 行」。

## 教学

`TechniqueInfo.walkthrough`（以及会点名格子的 `howToSpot` / `definition` / `caveats`）同样用这套记号。能画成链的例题，walkthrough 里至少有一行完整链表达式，与盘上绿起点 / 黄终点 / 实线强 / 虚线弱一致。

界面按钮文案保持中文，不改成英文缩写。
