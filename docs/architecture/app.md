# 产品与求解策略

教学向数独：对局里一次只教一步；技巧说明是独立静态页。禁止把无说明的回溯填数当成提示。

完整技巧名、难度和实现缺口见 [技巧总览](../techniques.md)。

## 信息架构

底栏两个入口，状态分开：

- **对局：** 选题难度 / 手动输入、计时计分、标记画板、逐步提示。
- **技巧说明：** 按从易到难的目录；每项一页固定文案 + 只读例盘（预制着色与箭头）。不演示、不填数、不跑求解、不覆盖对局棋盘。

没有「查看解法」。

## 对局提示

1. 点击提示只计算，不改盘。
2. 底部抽屉展示技巧名、原理、动作（填哪格 / 删哪些候选）和链表达式；棋盘用同一套标记画出参与格与强弱箭头。
3. 「应用」才改盘（填数或消候选，计一次提示）；「关闭」不改盘、不计提示。
4. 应用后抽屉不收起，立刻找下一步并原地替换。
5. 顺序从易到难；能用短名特例就不用通用 AIC。
6. Simple Coloring 保留并排在 AIC 之前；3D Medusa 并进 AIC，不单独报。
7. 唯一结构（唯一矩形、BUG 等）的说明须写明「题目保证唯一解」。

抽屉与布局细节见 [界面与教学内容](./ui.md)。

## 搜索策略

- 浅层：命名技巧 + AIC 约 12 个节点。
- 浅层无下一步且盘未完成：询问是否深度搜索。
- 深搜：同套技巧，链约 20 个节点，Forcing Net 扇出加倍。成功仍报真实技巧名，可附「（深度搜索）」。
- 深搜触顶仍无：告知失败，禁止回溯填数。

台词：

- 邀请：标题「这一步需要更深的推理」；正文「用到目前的全部技巧后，还找不到可以填数或删除的候选。可以进行一次更深的搜索（更长的链、更大的假设网），可能会稍慢。是否继续？」按钮「先自己想」「深度搜索」。
- 失败：标题「未能找到下一步」；正文「在限定深度内没有推出新的填数或删除。可以检查已填数字是否有误，或换一题继续练习。」

## 题集

- 技巧单测：每项至少一盘；来源可含 SudokuWiki / HoDoKu 例题，81 字符串检入仓库。
- 全盘回归：随包题库须能在浅层或深搜内走完，零无说明填数。
- 运行时不爬网。

## 非目标

- Multi-Coloring 独立报名
- Squirmbag / Whale / 模板 / 嵌套动态链
- Mutant 鱼、MSLS、动态 AIC（没有独立于通用搜索的判定）
- 双生鱼、自噬、BUG+n 作为独立提示名
- 手绘涂鸦
- 技巧说明页动态演示
